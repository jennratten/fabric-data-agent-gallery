# fabric-data-agent-gallery

A curated collection of Microsoft Fabric Data Agent demos showcasing various usage scenarios, features and implementation methods. This gallery is designed to help data engineers, architects, and solution builders explore and implement modern data integration scenarios using Microsoft Fabric.

---

## 🚀 Overview

Microsoft Fabric Data Agents enable seamless connectivity between Fabric and a wide range of data sources—on-premises, cloud-based, and SaaS. This repository provides hands-on examples of how to configure, deploy, and use Data Agents to ingest and orchestrate data pipelines within Fabric workspaces.

Whether you're just getting started or looking to implement advanced data movement scenarios, this gallery offers practical templates and guidance to accelerate your journey.
